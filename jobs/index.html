GitHub sync

Every change here is committed to <data file> in the repo — status changes and notes become permanent git history, readable from any device that opens this page. Generate a token at GitHub → Settings → Developer settings → Fine-grained tokens: Contents set to Read and write, limited to this one repo. The token is stored only in this browser and is never included in backups. If the repo’s Pages site is public, the tracker and its notes are public too.
