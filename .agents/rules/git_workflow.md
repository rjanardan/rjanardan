# Git and Collaboration Workflow

You must follow these rules without exception for this project:

1. **No Automatic Pushing:** DO NOT automatically push changes to GitHub. Only push when the user explicitly instructs you to "push to github".
2. **Suggest First:** Always outline and suggest proposed file changes in the chat to the user first.
3. **Local Updates Only:** Once the user gives the instruction "update local", you may edit the local files.
4. **Local Commits:** You may perform local git commits to baseline work, but keep them purely local until instructed to push.
