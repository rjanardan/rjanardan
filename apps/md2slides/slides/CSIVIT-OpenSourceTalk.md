# Richard Stallman's Free Software Foundation

“Free software” means software that respects users' freedom and community. Roughly, it means that the users have the freedom to run, copy, distribute, study, change and improve the software.

source: [original GNU Home](https://www.gnu.org/philosophy/free-sw.en.html) (HW: What annoyed RMS to start this movement?)

FREE != INR 0 (you can charge for software, distribution)

FREE = FREEDOM (to inspect, choice, not being controlled)

FREE != OPEN SOURCE
